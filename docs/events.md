# Event Taxonomy & Idempotency

Canonical event taxonomy conforms to strict `UPPER_SNAKE_CASE` groups:

### 1. Token Lifecycle
- `TOKEN_CREATED`
- `TOKEN_METADATA_UPDATED`
- `TOKEN_MIGRATED`
- `TOKEN_GRADUATED`

### 2. Pool / Liquidity
- `POOL_CREATED`
- `LIQUIDITY_ADDED`
- `LIQUIDITY_REMOVED`
- `LIQUIDITY_CHANGE`

### 3. Market
- `FIRST_TRADE`
- `BUY`
- `SELL`
- `SWAP`
- `PRICE_UPDATE`
- `VOLUME_SPIKE`

### 4. Wallet
- `WALLET_FIRST_SEEN`
- `WALLET_FUNDED`
- `TOKEN_RECEIVED`
- `TOKEN_TRANSFERRED`
- `TOKEN_BOUGHT`
- `TOKEN_SOLD`
- `CREATOR_ACTIVITY`
- `CREATOR_SELL`
- `WALLET_RELATION_DETECTED`
- `WALLET_CLUSTER_DETECTED`

### 5. Holder
- `HOLDER_FIRST_SEEN`
- `HOLDER_BALANCE_CHANGED`
- `HOLDER_COUNT_CHANGED`
- `TOP_HOLDER_CHANGED`
- `CONCENTRATION_CHANGED`

### 6. System
- `DATA_RECEIVED`
- `DATA_VALIDATED`
- `DATA_NORMALIZED`
- `DATA_DEDUPLICATED`
- `FEATURE_COMPUTED`
- `SCORE_COMPUTED`
- `SIGNAL_GENERATED`
- `ALERT_SENT`
- `OUTCOME_RECORDED`
- `BACKTEST_COMPLETED`
